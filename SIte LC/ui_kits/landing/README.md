# LeukoCheck Landing UI Kit

Marketing / product landing for LeukoCheck — the public site that explains the product to clinicians and drives demo requests.

## Files
- `index.html` — full landing composition
- `Nav.jsx` — sticky top navigation
- `Hero.jsx` — hero section with UTP + product preview
- `StatsBand.jsx` — key numbers (AUC, cohort, deaths prevented)
- `HowItWorks.jsx` — 3-step pipeline (ОАК → indices → model → risk)
- `Technology.jsx` — NLR / MLR / ИСНМ cards + neural net schematic
- `Evidence.jsx` — scientific base / publications
- `Audience.jsx` — "для кого" grid
- `Status.jsx` — TRL 6, patents, database
- `CTA.jsx` — final CTA block
- `Footer.jsx` — footer

## Structure mirrors the brief
1. Hero · 2. Problem · 3. Solution · 4. Technology · 5. Evidence · 6. Audience · 7. Advantages · 8. Status · 9. Team · 10. CTA / Contacts

Team section is intentionally minimal — names to be supplied.
